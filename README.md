# 手の速度・加速度ベクトル（5秒記録・再生版）

## 初期値
- 加速度表示: ON
- 速度ベクトル倍率: 2.00
- 加速度ベクトル倍率: 1.00
- 平滑化の強さ: 20%

## 使い方
1. `カメラ開始`
2. 手を画面に映す
3. `● 5秒記録` を押す
4. 5秒後に自動停止
5. `▶ 再生` を押す
6. 録画映像の上に、後処理で平滑化した速度（青）と加速度（赤）のベクトルが同期表示される

平滑化スライダーを変えると、同じ記録データから再生用ベクトルを再計算できます。

## GitHub Pages
このフォルダの `index.html` をリポジトリ直下に置き、GitHub Pages を有効にしてください。カメラ利用には HTTPS または localhost が必要です。

## 補足
- カメラ映像はブラウザ内の MediaRecorder で5秒だけ一時保持します。
- サーバーへのアップロード処理はありません。
- ベクトルはカメラ画像上の相対量で、実空間の m/s・m/s^2 には較正していません。
