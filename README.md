# 手の速度・加速度ベクトル（5秒記録・再生・6グラフ版）

## 初期値
- 加速度表示: ON
- 速度ベクトル倍率: 2.00
- 加速度ベクトル倍率: 1.00
- 平滑化の強さ: 20%

## 使い方
1. `カメラ開始`
2. 手を画面に映す
3. `● 5秒記録` を押す
4. 5秒後に自動停止
5. 記録終了後、6つのグラフが自動表示される
6. `▶ 再生` を押す
7. 録画映像の上に、後処理で平滑化した速度（青）と加速度（赤）のベクトルが同期表示される

平滑化スライダーを変えると、同じ記録データから再生用ベクトルと6グラフを再計算できます。

## グラフ
3行2列で次を表示します。
- 1行目: x-t, y-t
- 2行目: v_x-t, v_y-t
- 3行目: a_x-t, a_y-t

座標は再生画面中央を原点とし、右向きを +x、上向きを +y としています。
各行の左右2グラフは同じ縦軸スケールに自動調整されるため、x/y成分の大きさを比較できます。
再生・一時停止時には黄色の時刻線が6グラフに同期します。

## GitHub Pages
このフォルダの `index.html` をリポジトリ直下に置き、GitHub Pages を有効にしてください。カメラ利用には HTTPS または localhost が必要です。

## 補足
- カメラ映像はブラウザ内の MediaRecorder で5秒だけ一時保持します。
- サーバーへのアップロード処理はありません。
- ベクトルとグラフはカメラ画像上の相対量で、実空間の m/s・m/s^2 には較正していません。
