# 手の速度・加速度ベクトル

物理授業の演示用Webアプリです。

- 手のひら中心を追跡
- 速度ベクトル: 青
- 加速度ベクトル: 赤（初期OFF）
- 加速度表示は画面内の「加速度 ON / OFF」ボタンで切り替え
- 速度・加速度それぞれの表示倍率を調整可能
- 「平滑化の強さ」スライダーで、追従性とベクトルの安定性をリアルタイム調整
- Mac / iPad対応
- GitHub Pagesにそのまま配置可能

## 平滑化スライダー

- 小さい値: 反応が速い。細かな揺れや加速度ノイズも出やすい。
- 大きい値: なめらかで安定する。動きへの追従は少し遅くなる。
- 初期値: 60%

## ローカル実行

このフォルダでターミナルを開き、次を実行します。

```bash
python3 -m http.server 8000
```

その後ブラウザで以下を開きます。

```text
http://localhost:8000
```

## GitHub Pages

リポジトリのルートに `index.html` を置き、Settings → Pages から main / root を公開してください。
カメラ利用にはHTTPSが必要なので、iPadではGitHub PagesなどのHTTPS配信で使うのが確実です。

## 授業上の注意

表示している速度・加速度は、カメラ画像上のピクセル位置を時間微分した「相対ベクトル」です。
実空間の m/s, m/s^2 には較正していません。
加速度は二階微分なのでノイズが増えやすく、位置・速度・加速度に段階的な平滑化を入れています。
